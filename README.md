# Micro-Climate Nursery

ESP32-based automated nursery controller using DHT22, LDR,
servo ventilation, grow-light control, OLED, Blynk and ThingSpeak.

## Operating Modes
- AUTO
- MANUAL
- SAFETY

## Main Features
- Temperature and humidity monitoring
- Ambient light monitoring
- Automatic grow-light control
- Proportional servo ventilation
- Safety fault handling
- OLED display
- Blynk remote monitoring/control
- ThingSpeak historical logging
